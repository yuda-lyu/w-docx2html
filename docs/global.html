(async) autoDownloadFiles() → {Promise}

Description:

  • 自動定位docx2html.exe，若無檔案則自動下載，回傳docx2html.exe的絕對路徑

    依序偵測當前工作路徑的src/與node_modules/w-docx2html/src/，皆無docx2html.exe時， 代表安裝時npm封鎖scripts致postinstall未執行，故自動調用downloadFiles重新下載

    供w-docx2html自身與其他依賴w-docx2html的套件調用，無須各自實作偵測與下載邏輯

    因docx2html.exe只能用於Windows作業系統，故調用前須自行檢核作業系統

Source:
  • autoDownloadFiles.mjs, line 43
Example
import autoDownloadFiles from 'w-docx2html/src/autoDownloadFiles.mjs'

async function test() {

    //autoDownloadFiles, 無docx2html.exe時自動下載, 下載失敗則reject
    let { fpExe } = await autoDownloadFiles()

    console.log('fpExe', fpExe)
    // fpExe D:\xxx\node_modules\w-docx2html\src\docx2html.exe
}
test()
    .catch((err) => {
        console.log('catch', err)
    })
