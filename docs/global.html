(async) autoDownloadFiles() → {Promise}

Description:

  • 取得docx2html.exe，回傳docx2html.exe的絕對路徑

    相容層：本檔為舊版對外介面，內部改經ensureBins取得，依bin/manifest.json之SHA-256與大小校驗， 首次使用時下載(或自鏡像取得)，之後自快取取得，不再偵測當前工作路徑之src/與node_modules/w-docx2html/src/， 環境變數W_BIN_CACHE、W_BIN_MIRROR、W_BIN_OFFLINE見README〈外部執行檔〉

    因docx2html.exe只能用於Windows作業系統，故調用前須自行檢核作業系統

Source:
  • autoDownloadFiles.mjs, line 35
Example
import autoDownloadFiles from 'w-docx2html/src/autoDownloadFiles.mjs'

async function test() {

    //autoDownloadFiles, 取得docx2html.exe, 取得失敗則reject
    let { fpExe } = await autoDownloadFiles()

    console.log('fpExe', fpExe)
    // fpExe D:\xxx\node_modules\w-docx2html\bin-cache\<sha256>\docx2html.exe
}

ensureBins(optopt) → {Promise}

Description:

  • 取得本套件之外部執行檔docx2html.exe: 首次使用時下載(或自鏡像取得)並以bin/manifest.json之SHA-256與大小校驗, 之後自快取取得(亦校驗)

    規格: 外部執行檔之存放下載校驗與離線(制式規格)§6; 實作為wsemi之fsEnsureBins, 本套件不另寫下載、快取、鏡像、校驗 環境變數: W_BIN_CACHE(共用快取資料夾)、W_BIN_MIRROR(鏡像, 本地資料夾或http(s)網址)、W_BIN_OFFLINE(1為離線), 見README〈外部執行檔〉

Source:
  • ensureBins.mjs, line 36
Example
import ensureBins from 'w-docx2html/src/ensureBins.mjs'

async function test() {

    //部署前預先取得, 離線部署見README〈外部執行檔〉
    let bins = await ensureBins()
    console.log(bins['docx2html.exe'])
    // => D:\xxx\node_modules\w-docx2html\bin-cache\<sha256>\docx2html.exe

}
